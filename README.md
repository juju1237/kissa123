# kissa123

projektin idea on harjoitella vibe koodausta agentin avulla

palkitseva to-do lista ja virtuaalilemmikki
- käyttäjä voi valita
- käyttäjä voi lisätä omia tehtäviä
- käyttäjä voi valita tehtäviä valmiista listasta
- tehtäviä voi olla esimerkiksi tiskit, imurointi, koulutehtävä
- tehtävillä on eri painoarvoja
- tehtävän suorittamisen jälkeen saa erilaisia palkintoja kuten perusresursseja virtuaalilemmikille (esim. puuta, kangasta, ruoka-aineksia, kolikkoja).
- palkintoja yhdistelemällä voi saada isomman palkinnon esim. Yhdistelemällä puuta ja kangasta voi rakentaa lemmikille sängyn, tai ruoka-aineksista voi kokata herkkuja, jotka nostavat lemmikin tasoa

muuta toiminnallisuutta (suunnitelma):

Energiatasot: Tehtävät esimerkiksi kolmeen luokkaan:
- Nopeat (10 min): Tiskit, sängyn petaus -> Pieni palkinto (esim. 1 kolikko / perusraaka-aine).
- Keskikokoiset (30 min): Imurointi, kaupassakäynti -> Keskikokoinen palkinto (harvinaisempi materiaali).
- Isot urakat (1 h+): Koulutehtävä, vaatekaapin siivous -> Iso palkinto + yllätysarkku.

- Tehtävien pilkkominen (Sub-tasks): Jos käyttäjällä on iso koulutehtävä, hän voi jakaa sen pienempiin osiin. Jokaisesta osasta saa pienen palkinnon, ja koko tehtävän valmistumisesta saa bonuksen.
- "Päivän yllätystehtävä": Sovellus ehdottaa valmiista listasta yhtä satunnaista tehtävää tuplapalkinnolla.
- Reseptikirja: Sovelluksessa voisi olla "reseptikirja", josta käyttäjä näkee siluetteina, mitä kaikkea on mahdollista luoda (esim. 3x peruspalkinto = harvinainen palkinto, tai lauta + naula = linnunpönttö). Tämä luo uteliaisuutta ja tavoitteita.
- Satunnaisuus (Gacha / Yllätysmunat): Kun tehtävän tekee, palkinto voi tulla pienenä yllätyspakettina. Pieni jännitys siitä, mitä paketista paljastuu, vapauttaa dopamiinia
- Putket (Streaks) ilman syyllistämistä: Monissa sovelluksissa putki katkeaa, jos yhden päivän jättää väliin, mikä lannistaa käyttäjän. Tee tästä armollisempi: esimerkiksi "Viikon tavoite" (tee vähintään 15 tehtävää viikossa) tai virtuaalilemmikki, joka vain nukahtaa päiväunille, jos käyttäjä pitää vapaapäivän.
- Yksinkertainen "reppu" (Inventory), johon palkinnot kertyvät.
